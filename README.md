# Glass Phone

A single-file, interactive **glassmorphic phone UI** built with pure HTML, CSS, and vanilla JavaScript — no frameworks, build step, or dependencies.

## Features

- Glassmorphic design with frosted glass, blur, gradients, and soft shadows
- Animated background with floating color blobs and subtle grain texture
- Live clock and date on the home screen
- App grid and dock with tappable app icons
- App detail overlay with back/home navigation
- Power/lock button with a sleep screen
- Subtle 3D tilt effect following the mouse
- Responsive layout for shorter viewports
- Keyboard support: `Esc` closes an app, `Enter`/`Space` wakes the device

## Usage

1. Save the HTML file as `index.html`.
2. Open it in any modern browser.
3. Click app icons to open apps, and use the side **power** button to lock/unlock the device.

## Notes

- Everything is contained in a single HTML file — styles and scripts are inline.
- Icons are inline SVGs; no external assets are required.
